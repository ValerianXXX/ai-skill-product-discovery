# BillFit case reassessment, November 1, 2026

The [new preparation and reference execution](../../benchmarks/2026-11-01/README.md) repair one comparison-design gap. They do not replace the [October 29 observations](reassessment-2026-10-29.md), prove that a generic Agent needs a dedicated Skill, or establish customer demand.

| Question | Current evidence | Product implication |
| --- | --- | --- |
| Is assistance data an exclusive Skill advantage? | The maintained CPUC income ranges and all bounded decision semantics can be supplied equally to both general arms. | Test maintenance and reliable execution; do not claim exclusive access to public facts. |
| Did the old comparison treat reasoning equally? | Its shared snapshot omitted the FERA lower bound and CARE-priority convention. The new preflight rejects it for this new protocol. | Preserve the old result with its confound; freeze complete policy before new calls. |
| Did generic tools cause the old Agent's result? | The retained October 29 Agent used no broker tools. There are no new model observations. | Tool benefit remains unmeasured. |
| Is the previous short-CSV defect still present in current code? | Current BillFit completed the new duplicate-usage reference with an explicit `kwh` column. The old failed observation remains unchanged. | The specific input capability is now present in this tested draft; broader format reliability still needs its product evidence. |
| What is presently demonstrated? | Actual BillFit matches the declared fields for boundaries, missing/invalid income, stale versus expired rules, larger households, text conflict and short usage aggregation. | Auditable deterministic behavior is an engineering capability, not a measured superiority or actual savings claim. |
| Is Skill maintenance cheaper? | The isolated rule-change reference passes when all three bounds change. Human source review, implementation effort and attributable costs were not prospectively measured. | Measure these directly before a maintenance-cost claim. |

The [official CPUC source](https://www.cpuc.ca.gov/care/), checked November 1, supports the published income table and its dates. The 45-day review interval, output format and conservative fractional-gap response are declared product/research conventions. Their correctness for a bounded experiment does not verify a household's enrollment eligibility.

The next comparative campaign still needs independent policy review, an allocated budget and repeated observations. Live source retrieval, scanned bills, complete annual comparisons and user effort require separately scoped tasks. NeedRadar can use this as an internal engineering case; links among these repositories are not additional independent market evidence.
