The August discovery record remains a historical decision trail. Current source checks and actual substitute trials refine what can still be claimed.

The [three-arm results](../../benchmarks/2026-10-27/RESULTS.md) distinguish exact fields, current-source verification, abstentions and task completion. The model was the account's existing configured Hermes model, not an assumed latest model. New model/API availability was not needed to run this comparison.

The BillFit changes are reviewable in [draft PR #3](https://github.com/ValerianXXX/billfit/pull/3); they are not a released upgrade. Their 28 tests and source-verification records substantiate implementation, not independent demand. This case and NeedRadar must not cite each other's product documents as independent market evidence. V4 remains the highest fully evidenced validation level; customer acceptance, repeat use and realized savings remain unmeasured.

Next decisions should compare full supported interval tasks against a general Agent with equal source access, measure missing-input recovery and user corrections, and prospectively time source refresh/maintenance. A broad claim of product defensibility is premature without those observations.
