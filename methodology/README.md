# Methodology

This folder contains the reusable method behind the BillFit case.

- [Product-discovery framework](product-discovery-framework.md)
- [Evidence model](evidence-model.md)
- [Critical-data gap test](critical-data-gap-test.md)
- [Two-pass scoring model](scoring-model.md)
- [Validation ladder](validation-ladder.md)

Use the files in this order. The framework finds candidates, the evidence model controls claims, the data-gap test removes tasks a general assistant already handles, the scorecard ranks the survivors, and the validation ladder prevents engineering work from being mistaken for demand proof.
