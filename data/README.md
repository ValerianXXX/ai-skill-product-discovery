# Data

These files expose the main judgments and derived metrics behind the case.

- [`initial-opportunity-screen.csv`](initial-opportunity-screen.csv): the original twelve-candidate broad screen.
- [`critical-data-opportunity-screen.csv`](critical-data-opportunity-screen.csv): the second-pass screen added after the general-AI substitute challenge.
- [`evidence-ledger.csv`](evidence-ledger.csv): source, claim-state, caveat, and refresh records.
- [`github-trend-summary.csv`](github-trend-summary.csv): selected derived metrics from the 26-week technology-supply scan.

Scores are analyst judgments for prioritization. They are not market-size, adoption, revenue, or product-quality measurements.

The GitHub summary is derived from an archived Trending dataset with incomplete Top-20 coverage. It should not be used as a census of GitHub or as evidence of consumer demand.
