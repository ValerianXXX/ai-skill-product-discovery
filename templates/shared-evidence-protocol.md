# Shared-evidence case protocol template

Copy this into a new dated case. Fill it before observations and retain its freeze commit. Historical results must remain readable.

| Required decision | Record before calls |
|---|---|
| Task and scope | User outcome, supported inputs, irreversible actions withheld, synthetic versus authorized real data |
| Arms | Model/runtime versions; exact tools, native export abilities, domain code and data for each arm |
| Source coverage | Every expected fact and rule maps to a supplied source locator; distinguish facts in documents from rules only in Skill code |
| Policy semantics | Lower/upper bounds, precedence, exceptions, effective dates, missing information and invalid inputs |
| Response schema | Field names, nested structure, types, units, enum meanings, citation grouping and executable contract examples without answers |
| Validation before calls | Independent review or explicitly missing review; test non-answer fixture contracts; reject a claimed equal-information comparison when required policy is absent |
| Budget | Total adapter and measured provider-call ceilings, task deadlines, stop conditions, no selective retries, cost uncertainty |
| Sampling | Task families, development/calibration/held-out separation, repeated observations and known exposure |
| Maintenance | Isolated hypothetical source change, unchanged control, prospective preparation/review time, regression and activation boundary |

Keep four separate records: immutable raw observation; deterministic contract evaluation; dated content adjudication with reviewer and source; final interpretation. A response can have correct arithmetic but fail integration. A valid saved artifact can contain wrong facts. A completed analytical task need not complete a real-world transaction.

Report completion with a fixed denominator, critical numeric/date/attribution errors, missing fields, evidence coverage, actual tool use, saved-artifact provenance, user actions/edits, machine time, attributable cost and human maintenance effort. Unknown values remain null. Do not turn machine turns into user actions or included subscription estimates into verified zero cost.

If a protocol defect emerges, preserve it and its failed attempts, freeze any correction separately, label exposed calibration tasks and stop at the original budget. Do not silently normalize responses, change answer keys or backfill independent review. Future fair comparison may remain pending.
