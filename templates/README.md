# Templates

Copy these files when starting a new case:

- [`case-study-template.md`](case-study-template.md)
- [`opportunity-scorecard.csv`](opportunity-scorecard.csv)
- [`evidence-ledger.csv`](evidence-ledger.csv)
- [`validation-plan.md`](validation-plan.md)

Do not fill unknown fields with confident prose. Use `UNKNOWN`, state the next test, and preserve the distinction between a hypothesis and a result.
