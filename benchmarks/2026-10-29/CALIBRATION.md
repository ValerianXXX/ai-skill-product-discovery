# Protocol defect and separately frozen format calibration

The first equal-evidence pilot used exact field matching but failed to give models the complete accepted status vocabulary, bare numeric-string convention, canonical conflict IDs and one-entry-per-source citation rule. It therefore confounded meaningful correctness with undocumented integration conventions. Its strict 1/6 model and 1/6 Agent counts are **not valid factual task-success comparisons** with the already normalized Skill adapter. Do not promote its mismatched strings to factual errors or claim Skill superiority.

All original runs and failed artifacts remain unchanged. Actual evidence remains useful: the model returned correct selected income ceilings and unique-usage arithmetic; both model arms retained user-confirmation boundaries in the bill answer; BillFit rejected the frozen CSV with CSV_HEADER_NOT_FOUND. Some Agent responses also omitted the explicitly requested nested `fields` object; preserve those answer-contract failures separately. None of these observations proves general product quality or demand.

Before further calls, freeze `response-format.json` and a separate calibration containing current-income, conflicting-bill and duplicate-usage. Every arm gets the same evidence, fields and documented response vocabulary. Numeric answers and expected task decisions remain hidden. This is a post-discovery calibration on selected tasks, not a held-out quality estimate, a replacement first attempt or a directly comparable rerun.

The original model and Agent used six adapter calls each and no broker calls: 12 calls total, all with one measured provider API call. Of the original 28-invocation ceiling, at most 16 remain. The three calibration tasks allow at most three model calls and nine Agent calls. The already frozen hypothetical current-income maintenance variation allows at most one model and three Agent calls. No additional live cases or retries are allowed, even when the calibration fails. Skill calls are deterministic and use the same unchanged BillFit commit. There is no automatic escalation to a larger model or paid service.

Primary reporting must show original protocol defects, separate calibration outcomes, factual fields versus format conformance, actual broker use, artifact integrity, cost uncertainty and the unchanged synthetic maintenance boundary. A future generalization study needs new held-out tasks and independent review. The broader six-task initial run still supplies failure discovery; this smaller calibration does not cover every original task.
